## Research Highlight

### FTIR-Based Probiotic Microorganism Classification

Joint undergraduate thesis research focused on identifying probiotic microorganisms from **FTIR spectroscopy data** using machine learning and deep learning.

- **Dataset:** 100,000+ FTIR spectral samples
- **Compared models:** CNN, LSTM, CNN-LSTM, Random Forest, XGBoost, SVM and additional ensemble methods
- **Best model:** CNN with augmented data
- **Best test accuracy:** **92.31%**
- **Tools:** Python, TensorFlow, Keras, Scikit-learn, NumPy, Pandas

Joint research with [Gökçen Dilek Alak](https://github.com/gokcendilek).

[Explore the thesis repository →](https://github.com/gokcendilek/thesis_probiotic_classification_ai)
